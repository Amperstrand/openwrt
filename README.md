# Amperstrand/openwrt

AI experimentation workspace for conwrt bench research on OpenWrt.

- `main` is a pristine upstream mirror of [openwrt/openwrt](https://github.com/openwrt/openwrt) — **never pushed to**.
- All AI work happens on the `ai-experiments` branch.
- Issues in this repository are our lab notebooks, with evidence links to the [conwrt](https://github.com/Amperstrand/conwrt) repo.
- **Never interact with the upstream `openwrt/openwrt` repo from automation** — no issues, PRs, comments, or stars. Upstream is reference material only; only humans may touch it.
